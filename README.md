## Sobre o repositório

Este repositório foi criado com o objetivo de estudar conceitos de arquitetura, princípios SOLID e Design Patterns utilizando C#.
A proposta é manter exemplos simples, organizados e independentes, facilitando o entendimento de cada conceito de forma isolada. O conteúdo será expandido gradualmente conforme novos tópicos forem estudados.
O projeto possui caráter exclusivamente educacional e experimental, servindo como ambiente para prática, testes e aprendizado individual.
